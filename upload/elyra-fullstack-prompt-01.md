# برومبت البناء الأول — موقع وكالة Elyra الرسمي

## 0) قبل أي شيء
اقرأ دليلك الكامل `FULLSTACK_AGENT_GUIDE.md` من أوله إلى آخره والتزم بكل ما فيه: قواعد Next.js 16، تحصين الأمان، أنماط Prisma، قواعد i18n، فخاخ القسم 9 (Common Pitfalls)، وقائمة الفحص قبل النشر. هذا مشروع **جديد مستقل** لعلامة واحدة — وليس منصة التأجير متعددة العلامات — فطبّق المعايير الهندسية كاملة دون أي تعقيدات multi-tenant.

## 1) نظرة عامة على المشروع
ابنِ الموقع الرسمي لوكالة **Elyra** (تُكتب بالعربية: «إيليرا») — وكالة رقمية متخصصة في خطّي خدمة:
1. **بناء مواقع احترافية فائقة الجمال**: مواقع تعريفية، متاجر، منصات، وتجارب 3D تفاعلية
2. **بناء أنظمة أتمتة احترافية بـ N8N**: تكاملات CRM، فواتير، تنبيهات فورية، ووكلاء ذكاء اصطناعي

**الهدف التجاري**: موقع يجعل الزائر يعيش تجربة رقمية فريدة لم يعشها من قبل — بجمال Apple ووضوح Google — تُحوّل الإعجاب إلى طلب مشروع عبر حاسبة مشاريع تفاعلية.

**لغة الموقع**: عربية (افتراضية، RTL) + إنجليزية (LTR) — تكافؤ ترجمة كامل بنسبة 100%.

## 2) الهوية البصرية (مصدر الحقيقة الوحيد)

### الألوان — عرّفها مرة واحدة كتوكنز في نظام الثيم ويُمنع منعاً باتاً كتابة أي قيمة hex داخل المكوّنات:

| التوكن | القيمة | الاستخدام |

| `primary` | `#0071E3` (أزرق Apple) | الأزرار الرئيسية، الروابط، حالة التركيز |
| `background-light` | `#F5F5F7` | خلفيات الصفحات والأقسام الفاتحة |
| `foreground` | `#1D1D1F` | النصوص على الفاتح |

| `foreground-on-dark` | `#F1F5F9` | النصوص فوق الداكن (ليس أبيض نقياً) |
| `accent-google-*` | `#4285F4` · `#EA4335` · `#FBBC05` · `#34A853` | لمسات صغيرة بالعناصر التفاعلية فقط (نقاط، شرائط، أيقونات) — بحساب ودون إفراط |

### الخطوط
- **Inter** (لاتيني) و **Cairo** (عربي) عبر `next/font` — كلاهما Variable Fonts لاستخدامهما في التايبوغرافي الحركي
- سلم الأحجام: عناوين Hero ضخمة (`clamp(48px, 8vw, 96px)`)، عناوين أقسام كبيرة، نص أساسي 16–18px، شروح 13–14px

### الشعار
Wordmark نصي «Elyra» نظيف بحرف E مميز + نقطة رباعية صغيرة بألوان Google الأربعة (تلميح للهوية المزدوجة). نسخة SVG خفيفة.

### طابع التصميم — «الهجين المتدرج»
- صفحات فاتحة نقية + أقسام داكنة `#0F172A` درامية للعرض (Hero، المحاكي، الشهادات)
- زجاج مضيء Glassmorphism خفيف على البطاقات فوق الداكن
- مساحات بيضاء سخية بأسلوب Apple

## 3) الـ Stack والقواعد الإلزامية
Next.js 16 (App Router) · React 19 · TypeScript (strict) · Tailwind CSS 4 · next-intl 4 · Framer Motion · Three.js عبر React Three Fiber · Prisma 6 + SQLite (تطوير)

قواعد الدليل الحرجة (مكررة هنا للتأكيد):
- `await params` و `await searchParams` دائماً — التوقيعات أصبحت Promises
- `proxy.ts` فقط — لا تنشئ `middleware.ts` أبداً
- المكتبات الأثقل من 50KB تُحمّل ديناميكياً `ssr: false` مع loading fallback حقيقي (ليس null) — خاصة R3F/Three.js
- أمان Hydration: أي منطق زمني (ساعة حية، عدّادات) يُرسم بعد mount عبر `useEffect` + `mounted` flag
- تكافؤ مفاتيح `en.json` / `ar.json` بنسبة 100% مع سكربت فحص يفشل عند أي اختلاف
- خصائص CSS منطقية فقط للاتجاهات: `ms-` / `me-` / `ps-` / `pe-` / `start-` / `end-` — واختبر كل صفحة في RTL و LTR
- ملف `page.tsx` واحد لكل مسار + `loading.tsx` + `error.tsx` + `not-found.tsx` لكل مقطع
- كل ميزة حركية لها مسار `prefers-reduced-motion` بديل (بديل متدرج/ثابت راقٍ)

## 5) الصفحة الرئيسية — بهذا الترتيب حرفياً (معتمد من صاحب المشروع)

1. **Hero سينمائي**: خلفية WebGL داكنة (`#0F172A`) بجزيئات تنبض وتتبع الماوس بنعومة + عنوان ضخم بتايبوغرافي حركي متدرج الظهور + CTA مزدوج: «ابدأ مشروعك» (أساسي) و«شاهد أعمالنا» (ثانوي)
2. **شريط الثقة**: عدّادات إحصائية متحركة عند الظهور (مشاريع منجزة، ساعات موفرة شهرياً للعملاء، نسبة رضا، تكاملات جاهزة)
3. **شبكة خدمات Bento متوهجة**: بطاقات زجاجية بتوهج ديناميكي يتبع المؤشر + عنصر مصغّر تفاعلي داخل كل بطاقة يمكن للزائر اللعب به
4. **محاكي الأتمتة الحي**: قسم داكن — زر «جربها الآن» يشغّل محاكاة نبضات بيانات نيونية متدفقة بين عقد التطبيقات: استلام طلب ← تحديث قاعدة البيانات ← إرسال بريد ← إشعار تيليجرام، مع إضاءة العقد تباعاً وبطاقة توضيحية لكل خطوة — **هذا القسم هو جوهرة الموقع**
5. **أعمال مختارة**: بطاقات مع مقارنة قبل/بعد بسحب المؤشر
6. **منهجية العمل**: رحلة العميل في 4 خطوات (اكتشاف ← تصميم ← بناء ← إطلاق ودعم)
7. **شهادات العملاء**: اقتباسات أنيقة بتصميم زجاجي فوق الداكن
8. **حاسبة المشاريع**: معالج تفاعلي بأسلوب تخصيص منتجات Mac (المواصفة الكاملة في قسم الميزات)
9. **التذييل**: شارة «متاحون لمشاريع جديدة» نابضة + ساعة حية

**منطق الترتيب**: انتباه ← ثقة ← فهم ← تجربة ← إثبات ← إجراء.

## 7) الميزات التفاعلية — 14 ميزة معتمدة بالكامل

### أ) التجربة البصرية الحية
1. **خلفية WebGL سينمائية**: R3F بجزيئات Points (2–5 آلاف) تتنفس (حركة sin) وتنجذب بنعومة نحو الماوس (lerp)، DPR محدود بـ 2، إيقاف الرندر عند خروج القسم من الشاشة (IntersectionObserver) وعند إخفاء التبويب. بديل reduced-motion والأجهزة الضعيفة: تدرج داكن ثابت راقٍ
2. **سرد بالتمرير (Scroll-Driven Storytelling)**: الأقسام تدخل بتتابع تفكك/ترابط سلس (Framer Motion `useScroll` / `useTransform` + CSS scroll-timeline حيث يكفي) — بطاقات تنزلق وتستقر بأسلوب عروض منتجات Apple
3. **تايبوغرافي حركي (Kinetic Typography)**: العناوين الضخمة يتغير وزن الخط المتغير وحجمها مع تقدم التمرير. ملاحظة عربية: الحركة على مستوى الكلمات (الحروف العربية متصلة)
4. **تايبوغرافي عكسي**: عناوين أقسام بـ `mix-blend-mode: difference` فوق الصور والأعمال
5. **حبيبات سينمائية (Grain)**: طبقة noise خفيفة (SVG feTurbulence) فوق كامل الصفحة، شفافية منخفضة، `pointer-events: none`، ثابتة غير متحركة حفاظاً على الأداء

### ب) التفاعلات الدقيقة
6. **مؤشر مغناطيسي**: مؤشر مخصص (نقطة + حلقة) يتبع بـ lerp ويتمدد وينجذب للأزرار — يُعطَّل على أجهزة اللمس ومع reduced-motion
7. **توهج الزجاج الديناميكي**: كل بطاقة Bento تتبع الماوس بمتغيرات `--mx` / `--my` وتضيء حافتها (border + radial-gradient) — يعمل صحيحاً في RTL و LTR
8. **بطاقات متراكمة بأسلوب iOS**: بطاقات الأعمال والمنهجية تتراكم بـ `position: sticky` مع تصغير خفيف تدريجي
9. **مقارنة قبل/بعد**: منزلق سحب (clip-path) بين نسختي العمل — بالماوس واللمس وأسهم لوحة المفاتيح (وصولية كاملة)
10. **شارة التوفر + الساعة الحية**: نقطة خضراء نابضة + ساعة تتحدث كل دقيقة — hydration-safe (بعد mount فقط)

### ج) محاكي الأتمتة الحي (الميزة الفارقة تنافسياً)
11. **المحاكي**: مشهد SVG/Canvas بعقد تطبيقات أيقونية متصلة بخطوط — عند «جربها الآن» تتدفق نبضات نيونية على الخطوط (`stroke-dashoffset` animation) وتضيء العقد تباعاً مع بطاقة توضيحية لكل خطوة ومدة تنفيذ واقعية بالمللي ثانية، زر إعادة تشغيل، وفي صفحة الأتمتة سيناريوهات متعددة قابلة للاختيار

### د) الأتمتة الصوتية (اختيارية — تُنفَّذ في المرحلة الثانية)
12. **Audio UX**: أصوات اصطناعية فائقة النعومة عبر Web Audio API (بلا ملفات صوتية ثقيلة) عند التحويم والنقر وانتقال الأقسام — مطفأة افتراضياً، زر تبديل واضح بالزاوية، التفضيل يُحفظ في localStorage

### هـ) حاسبة ومخصص المشاريع التفاعلي
13. **المعالج بأسلوب تخصيص Mac** — 3 خطوات:
    1. اختيار نوع الخدمة: موقع 3D فاخر / نظام أتمتة / منظومة متكاملة
    2. تحديد الميزات والحجم: عدد الصفحات، اللغات، 3D نعم/لا، التكاملات المطلوبة، مستوى الأتمتة
    3. النتيجة: نطاق ميزانية تقريبي + مدة زمنية تقديرية + نموذج بيانات (اسم، بريد/واتساب)
    — بانتقالات ناعمة بين الخطوات، شريط تقدم، إمكانية الرجوع، تحقق Zod
14. **الإرسال الآمن**: `POST /api/leads` — تحقق Zod على السيرفر، **حساب الميزانية على السيرفر دائماً** (لا تثق بأي رقم من العميل)، Rate limiting، تخزين في Prisma + إطلاق ويبهوك موقّع إلى n8n

## 8) تكامل N8N — مستويان معماريان
1. **مستوى الخدمة المُباعة**: صفحات الأتمتة تعرض ما تبنيه الوكالة للعملاء (تكاملات، وكلاء AI، 422+ تطبيق جاهز)
2. **مستوى تشغيل الموقع نفسه**: كل طلب من الحاسبة أو نموذج التواصل:
   API Route (تحقق + تخزين) ← ويبهوك موقّع HMAC-SHA256 إلى n8n ← workflow يضيف الطلب إلى CRM الوكالة + يرسل بريد ترحيب للعميل + إشعار تيليجرام فوري

أمان الويبهوك (نمط الدليل كاملاً):
- توقيع HMAC-SHA256 + طابع زمني بصلاحية ±5 دقائق + nonce/idempotency
- الأسرار كمتغيرات بيئة فقط (32+ حرفاً): `N8N_WEBHOOK_URL` و `N8N_WEBHOOK_SECRET`
- الرسالة التسويقية المقصودة: «موقعنا يعمل بالأتمتة التي نبيعها — جرّب بنفسك»

## 10) معايير الجودة — تعريف «الاكتمال» (وليس it compiles)
- lint + tsc + سكربت تكافؤ i18n = **صفر أخطاء**
- Lighthouse 90+ (أداء، وصولية، ممارسات، SEO) لكل صفحة
- JS المبدئي للأقسام الساكنة أقل من 200KB (كل ما هو 3D/حركي lazy)
- WCAG 2.1 AA: تباين 4.5:1، `focus-visible` واضح، `aria-label` للأزرار الأيقونية، أهداف لمس 44px، تنقل كامل بلوحة المفاتيح (خاصة منزلق قبل/بعد والحاسبة)
- `prefers-reduced-motion` محترم في كل ميزة حركية
- RTL و LTR كلاهما مفحوص بصرياً بلا كسور
- SEO: metadata كاملة، hreflang، sitemap.xml، robots.txt، JSON-LD مرة واحدة لكل صفحة
- تحقق إلزامي في المتصفح: الصفحات تُرسم، التفاعلات تعمل، لا أخطاء console، sticky footer سليم
