### الوضع A — وكيل له وصول للملفات (Claude Code / Cursor / Codex CLI / Gemini CLI)

1. انسخ مجلد `agent-pack/` كاملاً إلى جذر مشروعك.
2. أضف إلى ملف قواعد الوكيل (`CLAUDE.md` أو `.cursorrules` أو `.mdc`) السطرين:
   ```
   عند أي عمل تصميم/حركة/أداء: التزم حرفياً بنتائج البحث في agent-pack/
   والتقييد بـ agent-pack/QA-CHECKLISTS.md قبل اعتبار أي مهمة منجزة.
   ```
3. افتح قالباً من `PROMPT-TEMPLATES.md` وعدّل متغيراته (نوع المشروع، اللغة، القيود) ثم أرسله.

### الوضع B — وكيل محادثة (ChatGPT / Claude / Gemini / Copilot Chat)

1. الصق محتوى `AGENT-INSTRUCTIONS.md` في أول رسالة (أو system prompt).
2. أرفق أو الصق التقرير المناسب لمهمتك — راجع مصفوفة الاختيار أدناه.
   - للمهام الكبيرة: `MASTER-REPORT.md` وحده غالباً كافٍ (هو التجميع الكامل).
3. أرسل البرومبت من `PROMPT-TEMPLATES.md` مع تفاصيل مشروعك.

### الوضع C — سياق محدود (وكيل صغير/مهام سريعة)

- الصق `QA-CHECKLISTS.md` + قسم الفصل المعني من `MASTER-REPORT.md` فقط.

## أهم 10 خلاصات حاكمة (الملخص السريع للوكيل)

1. **معادلة التحكيم:** Design 40% + Usability 30% = **70%** من درجة أي موقع فائز قبل أي إبداع — الأساسيات قبل المؤثرات.
2. **لحظة توقيع واحدة فقط:** كل مؤثر منافس يُحذف؛ الإتقان لتفاعل واحد 60fps.
3. **الأداء بوابة:** LCP < 1.5s، CLS < 0.05، INP < 100ms، < 3MB، 60fps ثابتة.
4. **منحنى واحد في كل مكان:** `cubic-bezier(0.16, 1, 0.3, 1)` + مدد 180/280/480ms — الاتساق يُقرأ كذوق.
5. **سر scrub الاحترافي:** `scrub: 1` لا `true`، و`ease: 'none'` داخل كل tween مقيّد بالسكرول، وربط Lenis بـ ScrollTrigger عبر "الساعة الواحدة".
6. **العربية معكوسة القواعد:** line-height 1.7–2.0، لا letter-spacing أبداً (يكسر الاتصال)، التقسيم بالكلمات لا الحروف، والحركة التحريرية translateX(100%).
7. **الأصول 80% من الفخامة:** أصل بصري واحد يصعب تقليده (تصوير/3D/ملمس ممسوح) يصنع الإدراك — "افعل ما يصعب على غيرك".
8. **AI Slop = انحدار نحو المتوسط:** العلاج قيود مسبقة (هوية/خطوط/ألوان/مراجع قبل التوليد) + حلقة screenshot → مقارنة → توجيه بالإحداثيات.
9. **سلّم التصعيد التقني:** CSS خالص أولاً → Motion للتفاعلات React → GSAP للسينمائي → WebGL للحظة الواحدة فقط.
10. **المعادلة الختامية:** أصل واحد + نظام تايبوغرافي + لحظة توقيع + أداء قاسٍ + اتساق = **80% من إحساس الـ$100K بميزانية $5–10K**.

## ملاحظات صدق منهجية (اقرأها قبل الاعتماد الكامل)

- ستة من وكلاء البحث العشرة (1-e…1-j) واجهوا rate-limiting (429) بسبب التوازي، فعوّضوا بحفر مجمعات نتائج مشتركة وإعادة استخدام نصوص مستخرجة — وُثّق ذلك داخل كل تقرير بشفافية. النتائج المرقمة تبقى قابلة للتطبيق مع مصادرها.
- الأرقام السوقية (أسعار/مدد/نسب) مستقاة من مصادر منشورة 2024–2026 وقد تتغير — استخدمها كنطاقات استرشادية لا كأسعار ثابتة.
- التقارير مكتوبة مركزياً لبيئة **Next.js + Tailwind + GSAP/Lenis**، لكن المبادئ قابلة للنقل لأي مكدس (React/Vue/Astro) بتعديل أسماء الأدوات.
